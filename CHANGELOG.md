# Changelog

## [1.1.0] - 2026-11-06

### Added

- EMI's recipe tree crafting mode now highlights [Traveler's Backpack](https://modrinth.com/mod/travelersbackpack) slots that hold items the tree still needs, the same way it does for a vanilla chest. Backpacks with a Crafting Upgrade are left alone, since EMI can craft from their contents and counts them toward the tree. ([#9](https://github.com/Mackery6969/EMI-Compat/issues/9))

## [1.0.1] - 2026-10-15

### Fixed

- Fixed a Neoforge security vulnerability where hackers could trigger denial-of-service attacks in a minecraft server.

## [1.0.0] - 2026-10-01

_Initial release._

### Fixed

- EMI's recipe tree crafting mode now highlights Sophisticated Backpacks and Sophisticated Storage slots that hold items the tree still needs, the same way it does for a vanilla chest. Storages with a Crafting Upgrade are left alone, since EMI already counts their contents toward the tree.
- EMI's slot overlays (recipe tree highlights and search highlighting) are no longer drawn as stray squares above large storages, for slots that are scrolled out of view or hidden by Sophisticated's search box.
